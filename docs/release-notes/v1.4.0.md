## New: a Windows installer

CrossPatch now comes with a proper installer, `CrossPatch-1.4.0-win-x64-setup.exe`.

- Installs for your user only by default: no administrator prompt. You can still install for everyone
- Adds a Start menu entry, an optional desktop shortcut and an entry in *Settings > Apps*
- Registers GameBanana's **1-Click Install** links, even before the first launch
- Installed copies update themselves by running the next installer, which waits for CrossPatch to close,
  installs over it and starts it again
- Uninstalling asks before deleting your settings and mods, and says exactly what would go

The portable zip is still published for anyone who prefers it. Your settings and mods live in
`%APPDATA%\CrossPatch` either way, so switching from the zip to the installer keeps everything.

## New features

- **Update all**: one button downloads every mod that has an update. The right archive is picked
  automatically when a mod offers several; you are asked only when it is really ambiguous
- **Conflicts window**: see which enabled mods change the same game files, grouped by the files they share,
  with the mod loaded last marked. Pick the one that should win and click *Load this mod last*. Conflicting
  mods are also shown in orange in the list
- **Filters** on the mod list: enabled, disabled, update available, in conflict, pak, UE4SS, with a counter
- **Drag and drop** a `.zip`, `.7z` or `.rar` onto the list to install it
- **Launch without mods** removes what CrossPatch installed into the game and starts it unmodded. Your mods
  and profiles are kept, and *Save* puts everything back
- **Browse Mods** can now sort by newest, recently updated, most liked, most downloaded or most viewed, filter
  by category, and marks the mods you already have as **Installed**. Thumbnails are cached, so going back a
  page is instant
- **Settings backups**: back up and restore your settings and profiles from *Settings*. A backup is also made
  automatically before every update and every restore
- **Log file**: *Settings > Open logs folder* gives you `crosspatch.log` to attach to a bug report, no need to
  turn the console on beforehand
- **Interface size** setting, set to 150 % automatically on the Steam Deck
- A **welcome screen** on first launch checks the game folder, UE4SS and the pak analyser, and explains the
  basics

## Security

- Updates are now checked against the SHA-256 checksum GitHub publishes for every release file before they
  are installed
- `crosspatch:` links are validated: CrossPatch only downloads from GameBanana, whatever a link says.
  Previously a crafted link could make it download an archive from any server while the confirmation window
  showed a genuine mod

## Bug fixes

- With a search active, saving or dragging a mod sent every hidden mod to the end of the load order
- Several background tasks never reported back: after an error the Refresh button stayed disabled, and the
  conflict check that follows analysing a new mod never ran
- Changing the game folder left the UE4SS folders pointing at the old one
- A crash while saving could leave a truncated config and lose every profile; settings are now written
  atomically
- Preview images in the download and 1-Click windows were created off the main thread, which Qt does not
  support

## Note for 1.2.0 to 1.2.2 users

The updater on your machine is the broken one from that generation, so its "Update" button cannot fetch this
release. Download it manually below, just this once. Your mods and settings are kept. From 1.2.3 onwards the
in-app updater works normally.

## Installation

- **Windows (recommended)**: run `CrossPatch-1.4.0-win-x64-setup.exe`. It is not code-signed, so SmartScreen
  may warn: click *More info*, then *Run anyway*
- **Windows (portable)**: extract `CrossPatch.1.4.0.zip` into a folder and run `CrossPatch.exe`
- **Linux / Steam Deck**: extract `CrossPatch-1.4.0-linux-x64.zip` and run `./run.sh`. Run `./install.sh` once for
  a menu entry and 1-Click links
